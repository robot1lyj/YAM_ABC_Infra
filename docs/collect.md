# 遥操作、数据采集与手柄按钮

硬件：2台官方YAM Leader、2台平行夹爪Follower、3台D405。按钮①/②对应SDK的top/second，首次实物联调确认位置。启动设备时释放按钮。

## 模式和操作

| 模式 | 控制方式 | 按钮① | 按钮② |
|---|---|---|---|
| 遥操作 teleop | Leader控制Follower；界面/键盘管理录制 | 无功能 | 无功能 |
| 推理 inference | Thor控制Follower，Leader不参与 | 无功能 | 无功能 |
| HIL | 键盘i冻结策略并自动进入人工纠正 | 仅人工阶段交还模型 | 无功能 |
| 数据采集 collect | Leader控制Follower，手柄管理episode | 开始/结束当前集 | 放弃当前集 |

左右手柄都能操作，按下沿触发，每种按钮250ms整站去抖，同时按同类按钮只触发一次。采集模式同时收到结束和放弃时，放弃优先；没有录制时按钮②无操作。手柄按钮不启动机械臂、不切模式、不退出程序。

## 遥操作和采集

```bash
uv run --no-sync yam-workstation --mock --mode collect --web-port 8766
```

1. 打开界面先创建/选择采集任务，再分别点击“连接相机”“连接机械臂”，等待四臂与三路相机就绪。用界面/键盘选择模式，按 `s` 启动遥操作。初始关节姿态须接近；夹爪扳机保留软接管保护。
2. 摆好场景，按手柄①（或键盘 `r`）开始录制，确认绿色录制按钮切换为结束录制，状态显示录制时长。
3. 完成示范，按①结束并保留；不满意则按②放弃。两者都不停止遥操作，便于准备下一次示范。
4. 每次新录制都是新episode。放弃的片段后台关闭编码器后删除，索引只保留discarded结果，不进入训练数据；不会删除前面的好数据。
5. 可用 `g/f` 标记成功/失败，未标记为unknown，保存不等于自动认定任务成功。
6. 空格单独暂停运动，取消排队运动指令。暂停/退出时未结束的采集标aborted；恢复用 `s`，录制需重新开始。
7. 结束录制后，支撑机械臂再点击“断开并保存”关闭设备。程序自动整理LeRobot数据，完成后界面回到未连接，可开始下一会话。不带界面的CLI用 `q` 退出。

遥操作模式默认连续录制，也可通过界面或 `r` 开关录制；手柄按钮始终无功能。推理/HIL默认会话连续记录，模式切换先暂停并切开片段。

真实设备去掉 `--mock`；先按 [硬件事实](workstation.md) 填写CAN、夹爪型号和三台D405序列号。构造设备可能施力矩并校准夹爪。空格是软件暂停，不是硬件急停。

## HIL / DAgger

HIL模型阶段，Leader镜像跟随Follower，因此手柄不能触发接管。键盘 `i` 是单向介入，不是接管/交还切换键。

- 接收到 `i`：废弃旧策略与在途结果，冻结Follower当前目标，并给Leader提交当前位置保持目标。
- 下一控制周期：Leader进入重力补偿，Follower由Leader相对于接管瞬间的位移控制，首个人工目标不因两者的小误差跳动。夹爪有软接管。
- 人工纠正后按手柄①：Follower暂时保持，重新取观测推理，Leader受限对齐；新策略和Leader就绪后恢复模型。
- 交还等待期再次按 `i` 可重新介入；手柄①在策略、冻结、等待阶段无功能；②全程无功能。

同一任务的策略、冻结、人工和恢复都在同一episode里。冻结是目标冻结，不是四台机械臂物理瞬时停稳的承诺。

## 数据与性能

`observation.state`来自与相机配对的Follower反馈；原始实时反馈另存。`action`是限幅后提交给Follower的绝对目标。Leader输入只用于控制和追溯，不能冒充Follower实测状态。

录制期间只做有界异步提交；视频编码、JSON序列化和关闭文件都在后台。会话结束、设备关闭后自动生成 `会话/lerobot/`，详见 [数据格式](convert.md)。运行时不会执行LeRobot转换。

原始会话保存全量状态/来源/策略回复/同步质量。LeRobot保留完整HIL阶段、人工有效标记、干预编号、事件请求/生效时间。观测短暂缺失时保留最近图像、用无效标志标出，不假装获得了新相机观测。

旧英文采集说明见 [归档](archive/collect-1c04c83.md)，只用于旧工具。

## 准备下一次示范

需要摆放机械臂时，先结束录制、暂停运动。在“设备与调试”进入重力补偿，手扶四臂摆到准备姿态，结束补偿后保存准备位。需要恢复姿态时点击“回准备位”，确认完整路径清空；完成后仍保持，回工作台点击开始并重新录制。回位与补偿期间不会录制维护动作。紧急暂停会把活动集标为中断；解除锁存不会接着执行旧动作。

三路预览可随时关闭，采集与落盘继续。预览最多5Hz，不等于相机采集帧率；卡片显示的fps来自相机帧序号变化，原始采集默认30Hz。


## 任务卡与独立连接

悟演智能工作台使用白色界面，顶部依次为连接相机、连接机械臂、软件急停。先在任务卡创建“乐高分拣”等任务，填写明确采集目标，例如“将桌面乐高按颜色放入对应收纳盒”。已有任务可重复选择，不需要每次新建。

任务目录保存在本机 `data/tasks/tasks.json`，不提交Git。原始会话与每集manifest的 `task` 是英文指令字符串；`collection_task` 保存中文名称、中文说明、英文task和稳定UUID。LeRobot任务文本使用英文task，`provenance.json`保留两种字段。界面数据目录为 `<output根目录>/<任务UUID>/session_时间_随机后缀/`，中文名称不直接用作路径。原始CLI无界面仍使用配置任务，不强制使用本机任务库。

相机连接只启动三路相机，未连接机械臂也可检查画面。机械臂连接只启动四臂并保持；此时可调试关节/夹爪，开始任务需要相机连接。断开机械臂后相机继续预览；断开相机需先暂停、结束录制与维护。正在机械臂会话或整理数据时不能更换任务，待会话保存完成后再选下一任务，防止混写。任务目录损坏会显示错误并拒绝覆盖。

预览仍由独立进程最多5Hz编码，浏览器最多4Hz请求最新JPEG；原始采集与记录不等待浏览器。任务目录读写发生在交互线程，不进入逐帧控制和视频落盘路径。


### 视觉优先的采集布局（2026-09-09）

任务改为紧凑栏，任务身份与目录说明放入“详情”；四模式使用同一切换条。视觉区以全局主画面和两路腕部画面为主体，可点“放大视觉区/恢复布局”。开始、暂停、录制、弃集与结果标记集中在右侧；仅HIL模式显示介入/交还按钮。急停在连接按钮旁保持大尺寸，未连接时禁用。日志默认折叠。布局调整不改变预览编码分辨率、频率或记录链路。

参考具身采集与回读流程：[LeRobot可视化](https://huggingface.co/docs/lerobot/using_dataset_tools)、[phospho采集指引](https://docs.phospho.ai/learn/improve-robotics-ai-model)。本界面布局是针对本工作站的设计，不声明与这些产品完全相同或达到行业认证。


### 中文显示名与英文 task

创建/编辑任务时分别填写：`name`（中文名称，供采集员识别）、`instruction`（中文操作说明）与必填 `task`（英文模型/数据集指令，最长300字符）。例如中文名“乐高分拣”，task为 `Sort the LEGO bricks by color into the matching bins.`。模型prompt、`station.task_name`、原始数据的`task`及LeRobot任务文本均使用英文task；中文字段保存在`collection_task`供追溯。

旧任务可正常加载，须在“详情→编辑任务”补填英文task才能连接机械臂开始新会话；保留原UUID。正在运行或保存的会话不允许修改任务。编辑只影响后续会话，历史文件不迁移、不改写。无界面CLI仍使用配置文件任务名。

维护页面使用蓝灰配色，准备位与重力补偿各一组操作，四个按钮最小高度78px，显示动作说明。大按钮沿用原有保持/录制互锁和操作确认，不改变电机控制路径。
