# 设备与采集：操作合同

本页描述当前代码，不代表 IPC 已部署全部更新。运行入口与恢复按钮见 [运行手册](hil_quickstart.md)，当前验收范围见 [验收](acceptance.md)。旧流程与现场记录完整保留在 [历史快照](archive/collect_20260922.md)。

## 四模式与手柄

| 模式 | 用途 | 手柄① | 手柄② |
|---|---|---|---|
| teleop | 无任务也能运行的纯遥操作，不录训练集 | 不分配功能 | 不分配功能 |
| collect | 同一遥操作实现，人工分集 | 开始/结束录制 | 放弃当前活动集 |
| inference | 模型控制 Follower，Leader 不镜像 | 不分配功能 | 不分配功能 |
| hil | 模型与人工纠正切换 | 介入等待时右①开始人工；人工时①锁定 | 无功能 |

按钮按下沿生效，持续按住不连续触发。collect 左右手柄都可操作；结束和放弃同时发生时放弃优先。没有活动集时②不删除历史数据。启动前释放手柄按钮。

### 遥操作与 HIL 共用实现

所有人工阶段复用同一绝对关节 1:1 映射、官方手动增益、SDK 重力及已开启的库仑摩擦补偿，夹爪复用软接管。**不再建立相对位移偏移**。Follower 仍受 SDK 硬限位；人工手感不是仅由一个补偿比例决定。

HIL 顺序：

1. 页面“介入”：清除旧模型计划，Follower 保持，Leader 辅助对齐。
2. 右 Leader①新按下沿：停止辅助对齐、进入人工遥操作，不要求误差达标。未对齐时绝对映射可能产生目标跳变，现场须确认姿态。
3. 人工阶段再按①：两侧保持，Leader 高增益锁定；**不自动交还模型**。
4. 页面“交还模型”：取新观测恢复策略，不沿用旧请求，不设已取消的 0.2 rad 主从就绪门槛。
5. 暂停和急停优先。故障介入可明确结束介入并切遥操作；切换后仍保持，不能自动运动。

策略阶段 Leader 与 Follower 使用同一最终关节目标、原生位置增益；这是目标一致，不保证不同负载下反馈瞬时一致。

## 从遥操作切到采集或换任务

连接机械臂不要求任务或相机，连接后保持，点击开始才遥操作。连接本身可能施加力矩，不是无害的只读动作。

从遥操作进入采集：暂停 → 连接相机 → 选择任务 → 切换采集 → 明确开始。不需要断开机械臂。

切换已绑定任务同样不要求断臂，但需处于 HOLD、结束介入/维护、结束录制且保存完成。后台创建新的数据 session，通过暂停屏障交换 writer；旧 session 的任务身份不改。初始化失败保留原会话，不把新任务写进旧数据。此能力及部署边界见 [架构](dagger_architecture.md#记录恢复与数据身份)。

任务使用稳定 UUID、中文显示名/说明及英文 task。模型 prompt 和训练任务文本使用英文 task；中文字段用于操作与追溯。历史数据不会随任务编辑改名或改写。

## 分集与保存

- collect：①开始，①结束保留；②仅放弃当前集。结束录制不结束遥操作。
- inference / hil：明确开始执行后记录 rollout。暂停运动结束本集，下一次明确开始创建新集；不是暂停后偷偷启动下一集。
- 遥操作始终不录训练集。会话元数据目录不等于录制了训练帧。
- 成功/失败由操作员标记，未标记为 unknown；保存完成不是抓取成功证明。
- 断开前先结束、等待保存，并支撑机械臂。断开 SDK 可能释放力矩。
- LeRobot 只由独立工具显式转换，工作台不在退出时自动转换。

当前 HIL 删去两段等待：介入到真正人工、人工锁定到点击交还；交还后的 RESUME 不在这两类删除范围内。视频和数值帧一起过滤，连续训练时间与原始审计时间同时保留。完整字段见 [数据合同](hil_dataset_fields.md)。

## 相机、初始化和维护

相机连接和机械臂连接独立；纯遥操作不要求相机，录制/模型依赖新鲜三路观测。预览低频、有界且可关闭，不代表采集只以预览频率运行。

新设备使用“设备与调试”初始化向导，复核配置、CAN 角色、相机序列号、夹爪行程及反馈；不要照搬另一台设备的标定。初始化不自动启动遥操作、回零或写编码器零点。步骤与安全补丁归 [工作站](workstation.md)。

本站默认 Follower 回零是六关节目标为零、保持夹爪；Leader 有独立回零入口，使用原生位置增益。保存/回准备位与重力补偿属于显式维护，不是训练动作。回零无碰撞规划，完整路径须现场确认。软件暂停不能替代实体急停。

夹爪调试：在“设备与调试”选择左或右 Follower，输入 **0～1 的绝对目标开度**再点“应用”；
`0` 为闭合、`1` 为张开、`0.15` 为 15%。旁边显示实时反馈百分比，输入本身不会触发运动。
仅在连接且 HOLD、无录制/介入/其他维护时可用；沿用单一 Runtime 点动通道，
以 0.25 开度/秒接近目标，最多追踪 6 秒，暂停/急停会取消，不自动恢复。
只调整所选侧夹爪，其他目标保持；归一化开度相等不代表物理毫米缝隙已验证一致。

## 录制失败与资源边界

控制仅提交有界队列；图像暂存、编码、HDF5、最终封装在后台。允许停录后排空，不允许无限 RAM 积压。队列满不等于机械臂通信队列满，也不能只放大队列掩盖持续吞吐不足。

录制故障可请求 HOLD；新版“恢复录制服务”后台创建新数据 session，保留失败原件，不重连 SDK。失败集在途 RAM 不保证可救；离线恢复只能使用已落盘的可读 segment/spool。规则、局部恢复、部署状态归 [架构](dagger_architecture.md#故障等级与恢复合同)。
