## 检查工具负责什么

`scripts/check_project_memory.py` 复用现有检查器：检查当前文档文件/章节链接、热预算、重复record ID、所有者路由和结构/时效；默认 `basic` 不计算证据/依赖哈希。缺失来源单独提示复查，不自动提升或修复记录。`--details` 才列历史明细。

```bash
python3 scripts/check_project_memory.py
python3 scripts/check_project_memory.py --integrity strict
```

只有精确产物身份影响本次决策，或适用合同明确要求时才用 `strict`。它检查原有指纹，不能通过刷新哈希掩盖变化；不因出现“训练/部署”字样自动启用。basic也不允许路径逃逸、范围混用、未来时间或将失效状态当作当前结论。

检查器不验证语义、现场可达性或实际token占用；不执行记录里的命令，不重置上下文，不控制设备。

## 选择性检索与计量边界

仓库的 `scripts/memory_gate.py` 与对应离线测试同步当前安装技能，作为可选工具；普通有界读取同样可用。

```bash
python3 scripts/memory_gate.py init --root . --session TASK
python3 scripts/memory_gate.py pack --root . --session TASK --required 'docs/hil_quickstart.md#操作规则'
python3 scripts/memory_gate.py audit --root . --session TASK
```

- 默认 `--integrity basic`：检查结构/范围/时间/路径，明确标记 `fingerprints_not_checked`；缺失本地来源标记 `source_unavailable`/`recheck_required`。没有指纹不阻断普通工作，已知相关内容改变仍须定向复查。
- 精确版本审计给 `pack/search/validate-record` 加 `--integrity strict`；basic读取不抵消后续strict校验。
- 每包默认12,288序列化UTF-8字节，`pack --max-bytes` 可调；必需章节整段保留。包超限先缩小无关选择，必要时提高包大小，不能截掉条件来适配。
- 无默认累计额度；ledger在忽略的 `docs/cache/runtime/`，不提交。旧显式额度保留，只有已获授权更改时才 `resize` 并记录原因，不重建session规避。
- 未变化选择去重；压缩后缺失的章节才 `--reload`。去重哈希不是来源完整性认证，ledger不知道宿主实际保留了什么。
- `tracked_bytes` 是声明预载加已输出包的累计传输量；`context_tokens=null`。写checkpoint不会清除聊天历史，不能据字节声称节省了多少token或扩大模型窗口。
