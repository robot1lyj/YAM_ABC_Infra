# 数据转换与模型微调

本项目负责采集、记录和专家段导出；模型微调、转换与 Thor 服务由 `/home/wuyan-lyj/condapi` 管理。

## 正常交接

1. 按 [采集手册](collect.md)获得完整 episode，检查是否成功保存、有无错误。
2. 按 [专家导出与转换](convert.md)生成连续人工片段，不能把策略动作作为专家标签。
3. 审核任务 prompt、图像角色、动作单位、归一化和观测/动作时间对齐，记录数据身份和划分。
4. 在 condapi 的当前训练规范下选择模型/配置，运行与记录训练；本仓库不默认启动训练。
5. 通过冻结观测和模型输出验收后，再回到 [部署手册](deploy.md)联调。

已读取的 condapi 规范快照默认采用 Pi0.5 全量微调 `pi05_yam`，不是旧文档中的 LoRA 默认；后续训练前要重新核对源项目。详见 [对接规范](condapi_interface.md)。

旧仓库仍保留 OpenPI、MolmoAct2、ABC 等训练工具，其互斥依赖组不能全部混装。它们不是当前 RK3588 工作站的默认环境。若需要追溯旧命令，可读 [上游英文归档](archive/training-1c04c83.md)，不得把其中历史 GPU/训练验证范围当作当前硬件验收。
