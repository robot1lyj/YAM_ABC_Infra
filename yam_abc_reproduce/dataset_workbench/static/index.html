检查已选数据

文件可读性、行数、14 维状态与动作、有限值、时间戳、控制帧间断、三路视频索引。

原始数据额外完整解码和内容指纹检查；LeRobot检查该集对应的视频时间范围。耗时随数据量增长。

原始数据转换为 LeRobot

输入必须为完整原始采集包（HDF5/JSONL＋MP4＋清单）；把所选原始集合并为一个 LeRobot v3.0 数据集。英文 task 分别保留；帧率需一致，失败集仅在选中时导出。

完整连续视频优先免重编码；筛选片段需要重编码。生成来源清单与 SHA-256 指纹，原始数据保留，输出不覆盖。

打包迁移

打包所选集、审核备注和集合关系。迁移包使用相对路径；拷贝到另一台机器后，通过“恢复迁移包”重新定位数据。

LeRobot多集可能共享文件，打包会携带对应的完整来源目录；审核索引只包含所选集。原始数据不改动，MP4不重复压缩。

恢复迁移包

逐文件校验 SHA-256，恢复原始数据、格式标记、审核和集合。无需保留原机器的路径。
